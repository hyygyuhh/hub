架集是什么？

架集 ShelfHub 聚合 GitHub 热门开源软件，按用途分类（AI、开发、系统、影音等），并提供国内网盘镜像下载。

如何筛选软件？

可按平台（Windows / Android）与分类浏览，每款软件标注 GitHub 仓库、Star、版本，方便核对来源。

镜像从哪来？

安装包对应 GitHub Release，由维护者同步至夸克、百度公开网盘；未配置镜像的条目可先查看上游仓库。
